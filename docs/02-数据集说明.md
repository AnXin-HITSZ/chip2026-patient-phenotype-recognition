# 数据集说明

数据集名称：**PatientPheX** — 专门用于评估「患者表型个体化信息抽取」的全文级标注数据集，来源于 PMC 公开发表的生物医学文献。目前共 **200 篇**全文级人工标注文献，每篇均标注了患者信息、表型实体及患者与表型之间的关联关系。

> 本页统计已与本仓库 `data/PatientPheX-V1-A/` 下实际发布的 A 榜数据（训练集 + A 榜测试集）逐项核对一致。

---

## 1. 数据规模

| 统计项 | 训练集 | 开发集（A 榜） | 测试集（B 榜） | 总共 |
|---|---|---|---|---|
| 文献数 | 80 | 20 | 100 | 200 |
| 患者数 | 209 | 53 | 244 | 506 |
| 表型实体提及数 | 6027 | 1563 | 7603 | 15193 |
| 唯一 HPO ID 数 | 1662 | 551 | 1863 | 2874 |
| 否定表型数 | 171 | 38 | 226 | 435 |
| 复合表型数 | 69 | 5 | 138 | 212 |
| 患者表型关联数 | 2307 | 563 | 2786 | 5656 |
| 患者相关唯一 HPO ID 数 | 1091 | 351 | 1252 | 1995 |

- **训练集** 80 篇，包含完整答案（`entities`、`association` 非空）。
- **开发集（A 榜测试集）** 20 篇：`entities` 与 `association` 为空，答案不公开，需在线提交。A 榜答案不会公开，也不用于 B 榜模型训练。
- **测试集（B 榜测试集）** 100 篇：B 榜阶段释放，`entities` 与 `association` 为空，需在线提交。B 榜历史最优成绩作为最终排名依据。

> 说明：CHIP 官网评测页将训练集「唯一 HPO ID 数」写作 1666，主办方 GitHub 与本仓库实际数据均为 **1662**，本页以实际数据为准。

## 2. 文件清单

当前 A 榜数据包 `PatientPheX-V1-A/` 内含：

| 文件 | 说明 |
|---|---|
| `PatientPheX-train.jsonl` | 训练集，80 篇，含完整答案 |
| `PatientPheX-A.jsonl` | A 榜测试集，20 篇；`entities`/`association` 为空 |
| `PatientPheX-B.jsonl` | B 榜测试集，100 篇（B 榜阶段释放）；`entities`/`association` 为空 |
| `submit_pred_ex.jsonl` | 提交格式示例（取自训练集，不含开发/测试集答案） |
| `hp.obo` | HPO 本体文件，版本 `hp/releases/2026-06-23`，含 20,413 个 `[Term]` |
| `README.md` | 官方数据说明 |

所有文件均为 **UTF-8** 编码。JSONL 每行是一篇文献，文章按原始 PMC JSON 文件名的**字典序**排列。

## 3. 数据格式

数据采用 **JSONL** 格式，每行对应一篇文献，字段顺序固定。顶层结构如下：

```json
{
  "pmc_id": "12652105",
  "pmid": "41300704",
  "patient": [
    {
      "patient_id": "OII.1",
      "mention": [
        { "text": "an 18-year-old female", "offset": 10434, "length": 21 },
        { "text": "patient one (II.1)",    "offset": 12645, "length": 18 }
      ]
    },
    { "patient_id": "OII.2", "mention": [ { "text": "Patient II.2", "offset": 13059, "length": 12 } ] }
  ],
  "full_text": [
    { "section_type": "TITLE",    "type": "front",    "offset": 0,  "text": "Rare Duplication in the RYR1 Gene ..." },
    { "section_type": "ABSTRACT", "type": "abstract", "offset": 90, "text": "..." }
  ],
  "entities": [
    { "identifier": "HP:0002047", "type": "Phenotype", "offset": 42, "length": 22, "text": "Malignant Hyperthermia", "note": null }
  ],
  "association": [
    { "patient_id": "OII.1", "phenotype": ["HP:0003938", "HP:0001945", "HP:0002063"] },
    { "patient_id": "OII.2", "phenotype": ["HP:0001762", "HP:0000508"] }
  ]
}
```

## 4. 字段说明

| 字段 | 二级字段 | 示例 | 说明 |
|---|---|---|---|
| `pmc_id` | | `12652105` | PMC 全文编号（文献主键） |
| `pmid` | | `41300704` | PubMed 文献编号，可能为 `null` |
| `patient` | | | 本文**指定患者**列表 |
| | `patient_id` | `OII.1` | 患者唯一标识：文章出现具体编号则为「`O` + 文中的编号」，其他为 `P` 开头按出现顺序编号 |
| | `mention` | `patient one (II.1)` | 患者在正文中的**部分**有效文本指称（非全部），含位置信息 |
| `full_text` | | | 文献全文正文内容（段落列表） |
| | `section_type` | `TITLE` | 章节类别（TITLE / ABSTRACT / INTRO / METHODS / RESULTS / CASE / DISCUSS / CONCL / FIG / TABLE / KEYWORD …） |
| | `type` | `front` | BioC passage 的细粒度类型 |
| | `offset` | `0` | 该章节在**原始完整全文**中的全局起始字符位置 |
| | `text` | | section 的原始文本 |
| `entities` | | | 正文部分**所有**表型信息 |
| | `identifier` | `HP:0002047` | 标准化 HPO ID；复合表型用**分号**分隔；无有效 ID 时为 `-1` |
| | `type` | `Phenotype` | 实体类型，当前均为 `Phenotype` |
| | `offset` | `42` | 实体在原始完整全文中的全局字符位置 |
| | `length` | `22` | 实体文本的字符长度 |
| | `text` | `Malignant Hyperthermia` | 实体在原文中的实际文本 |
| | `note` | `null` / `NO` | 附加标记；默认 `null`；`NO` 表示**否定表型** |
| `association` | | | 文中所有患者关联信息 |
| | `patient_id` | `OII.1` | 患者唯一标识，与 `patient[].patient_id` 对应 |
| | `phenotype` | | 患者关联的表型字符串列表：有效表型保存 HPO ID；原始 ID 为 `-1` 的表型保存**原文文本** |

**关键约定**：所有 `offset` 均为**原始完整文章**中的全局字符位置。跨段落定位时需依据每段的 `offset` + `text` 重建全局字符索引，文本清洗时务必保持 offset 对齐（不要改变字符数）。详见 [06-技术背景](06-技术背景.md)。

## 5. HPO 本体（`hp.obo`）

- 版本：`hp/releases/2026-06-23`（评测强制使用此版本）。
- 仅评测 **Phenotypic abnormality（HP:0000118）** 分支下的概念。
- 文件格式为 OBO，含 20,413 个 `[Term]`。示例词条：

```
[Term]
id: HP:0000002
name: Abnormality of body height
def: "Deviation from the norm of height ..." [https://orcid.org/0000-0002-0736-9199]
synonym: "Abnormality of body height" EXACT layperson []
xref: UMLS:C4025901
is_a: HP:0001507 ! Growth abnormality
```

本体信息可参考官网 https://hpo.jax.org/ 。HPO 结构、同义词/过时词条处理与词典构建方法见 [06-技术背景](06-技术背景.md)。

## 6. 数据统计小工具

本仓库提供 `scripts/prep/inspect_data.py`，可对任意 jsonl 复算上表各项统计并做 offset 校验，便于验证数据完整性与自研预处理是否破坏了 offset 对齐。
