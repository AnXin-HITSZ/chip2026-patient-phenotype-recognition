## 2. 奖励设置

本任务为**学术评测任务**。获奖队伍将获得**获奖证书**，进行**大会汇报**，并**发表英文评测论文（EI 收录）**。

## 3. 参赛规则

1. 每名选手仅限注册一个账号；一旦发现注册多个账号进行提交，将取消所有账号的参赛资格。
2. 在 A 榜结束前，填写报名信息表（官方报名表：https://docs.qq.com/form/page/DRE5IVEJJbnRvZkhK ）。
3. 允许使用外部资源（代码、工具、知识库等），但**不允许使用外部人工标注表型数据集**；所用资源须是公开可获取的，并注明来源。
4. 获奖队伍需注册并参加 CHIP 会议，在会议上进行口头汇报、撰写技术论文，否则取消参赛成绩、名次递补。（会议注册费、食宿交通费用自理。）
5. 国内外在校生及企业人员均可参赛，个人须依托单位报名。参赛队伍（含队长及全体成员）需在报名截止前完成**实名认证**（入口：官网右上角个人中心 → 认证），未完成认证将被取消资格。
6. 组队人数限制 **1–5 人**。
7. 该任务数据仅用于本次评测，如需用于其他目的请与组织者联系。

## 4. 获奖队伍材料提交

获奖队伍需提交：

1. 相关代码及说明。
2. 评测论文（可参考往届 CHIP 评测论文：http://www.cips-chip.org.cn/2024/accepted ）。
3. 若使用了额外公开资源，需说明并提供资源文件或地址（代码、工具、知识库等，须公开可获取）。

提交方式：在评测论文提交截止日期前发送至邮箱 **dutir_bionlp@163.com**，邮件标题为「**CHIP2026Task-评测材料-参赛队伍名称**」。代码及文档打包为一个文件（zip / rar 均可）作为附件。

> 若未提交上述材料，将视为自动放弃评奖，资格顺延至排名紧随其后的队伍。

## 6. 基线系统（官方）

官方 Baseline：

1. **子任务 1**：使用指定版本 HPO 训练的 **PhenoTagger** 对全文进行表型概念识别。
2. **子任务 2**：使用 **Qwen3-8B** 大语言模型，通过提示词工程识别文本中指定患者的相关提及，再结合上下文将患者与已识别的表型实体进行关联。

整体方法**并未使用训练集优化**。基线方法解析与改进思路见 [07-基线与打榜策略](07-基线与打榜策略.md)。
