# 评测指标

本评测综合考虑两个子任务的性能表现。最终得分（Score）由子任务 1 与子任务 2 的指标加权计算得到：

$$Score = 0.25 \times (F1_{men} + F1_{doc}) + 0.25 \times (F1_{micro} + F1_{macro})$$

其中 $F1_{men}$、$F1_{doc}$ 来自子任务 1，$F1_{micro}$、$F1_{macro}$ 来自子任务 2。四项等权，各占 25%。

---

## 1. 子任务 1：全文表型概念识别

从**实体提及级别**和**文档级别**两个粒度评价。

### 1.1 实体提及级别评价（Mention-level）

用于衡量模型对具体表型文本实体的识别和标准化能力。

- 对每一个预测表型实体，**只有当预测的表型实体边界与真实标注完全一致，且其对应的 HPO 概念标识正确时**，才被视为正确预测（TP）。
- 预测的表型实体不存在于真实标注集合中 → 假阳性（FP）。
- 真实标注中的表型实体未被正确识别 → 假阴性（FN）。

$$P_{men} = \frac{TP}{TP + FP} \qquad R_{men} = \frac{TP}{TP + FN} \qquad F1_{men} = \frac{2 \times P_{men} \times R_{men}}{P_{men} + R_{men}}$$

> 提及级要求**边界 + HPO ID 双双正确**，是最严格的粒度。

### 1.2 文档级别评价（Document-level）

用于衡量模型是否能够识别文献中出现的表型概念集合，**只关注 HPO 概念是否在文档中被识别，不考虑其具体位置、边界与出现次数**。

对每篇文档，将真实标注表型实体对应的 HPO ID 去重后形成真实集合 $G_d$，将预测结果的 HPO ID 去重后形成预测集合 $P_d$：

$$G_d = \{h_1, h_2, \ldots, h_n\} \qquad P_d = \{h_1, h_2, \ldots, h_m\}$$

若某 HPO ID 同时存在于 $G_d$ 与 $P_d$，则该概念预测正确。跨 $N$ 篇测试文档累加：

$$TP_{doc} = \sum_{d=1}^{N} |G_d \cap P_d| \qquad FP_{doc} = \sum_{d=1}^{N} |P_d - G_d| \qquad FN_{doc} = \sum_{d=1}^{N} |G_d - P_d|$$

$$P_{doc} = \frac{TP_{doc}}{TP_{doc} + FP_{doc}} \qquad R_{doc} = \frac{TP_{doc}}{TP_{doc} + FN_{doc}} \qquad F1_{doc} = \frac{2 \times P_{doc} \times R_{doc}}{P_{doc} + R_{doc}}$$

### 1.3 否定 / 复合 / 无 ID 实体判定说明

- **否定表型（`note="NO"`）**：表示文本中明确否定的临床表现，不属于患者实际表型信息，**不作为正例参与评价**。
  - 金标准中标记为 `note="NO"` 的实体**不计入 FN**；
  - 预测结果若正确将该实体标记为 `note="NO"`，则**不计入评价**；
  - 若模型将该否定表型预测为**普通**表型（未标 `note="NO"`），则算错误预测，**计为 FP**；
  - 若模型**未预测**该否定表型，则不计分。
- **复合表型（ID 用分号隔开，如 `HP:xxxxxx;HP:xxxxxxx`）**：一个表型实体对应多个 HPO ID 时，评测将多个 ID 按**分号拆分为独立评价单元**，分别匹配计算。
- **无 ID 表型（ID 为 `-1`）**：预测**位置信息正确即为正确**。

## 2. 子任务 2：特定患者表型概念识别

评价对象为**患者与表型之间的关联关系**。仅当模型准确关联给定患者对应表型时，该「患者-表型」映射才被视为 TP；错误地将某表型归属于该患者 → FP；未能识别该患者关联的真实表型 → FN。

### 2.1 微平均 F1（Micro-F1）

从全局角度评估所有「患者-表型」映射关系的整体抽取性能，将测试集视为一个整体，把所有文档的 TP、FP、FN 全局累加：

$$P_{micro} = \frac{\sum TP}{\sum TP + \sum FP} \qquad R_{micro} = \frac{\sum TP}{\sum TP + \sum FN} \qquad F1_{micro} = \frac{2 \times P_{micro} \times R_{micro}}{P_{micro} + R_{micro}}$$

### 2.2 宏平均 F1（Macro-F1）

以**单个患者**为单位分别计算 P、R、F1，再对所有患者等权平均，用于评价模型识别患者个体化表型的能力。对第 $i$ 位患者，真实表型集合为 $y_i$，预测表型集合为 $\hat{y}_i$：

$$P_i = \frac{|y_i \cap \hat{y}_i|}{|\hat{y}_i|} \qquad R_i = \frac{|y_i \cap \hat{y}_i|}{|y_i|} \qquad F1_i = \frac{2 \times P_i \times R_i}{P_i + R_i}$$

$$P_{macro} = \frac{1}{K}\sum_{i=1}^{K} P_i \qquad R_{macro} = \frac{1}{K}\sum_{i=1}^{K} R_i \qquad F1_{macro} = \frac{1}{K}\sum_{i=1}^{K} F1_i$$

其中 $K$ 为测试集中金标准患者的总数。**当某患者的真实表型集合与预测表型集合均为空时，其 P、R、F1 均定义为 1。**

## 3. 排名与更新

- 排行榜整点更新，按评测指标（Score）从高到低排名。
- 评测失败不扣除提交次数。
